## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Session Manager** | Organize your ACC track sessions with notes and telemetry links |
| **Setup Library** | Store and compare car setups across different tracks |
| **Lap Analyzer** | Compare lap times and sector splits from your sessions |
| **Quick Launch** | Launch ACC directly into your saved session configuration |
